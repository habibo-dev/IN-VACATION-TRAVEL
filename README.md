# In Vacation Travel

Site vitrine premium pour In Vacation Travel, agence de voyage à Khemis Miliana, Aïn Defla.

## Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- React 19
- Lucide React
- Zod

## Déploiement

Le projet est configuré pour Vercel et utilise `main` comme branche de production.

Les informations commerciales non vérifiées sont volontairement présentées comme configurables afin d'éviter toute fausse promesse.
